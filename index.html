01 Toy ECC Encryption (secp256k1 with Restricted Key Space)

This scheme implements an EC-ElGamal / ECIES-style hybrid protocol on the secp256k1 curve ($y^2 \equiv x^3 + 7 \pmod p$, standard generator $G$). To make algorithmic cryptanalysis tractable in the browser, the scalar private key $d$ is restricted to a small bounded range ($d \in [1, 2^b]$). The ephemeral point $C_1 = k \cdot G$ and shared secret $S = k \cdot Q$ produce a keystream from coordinate $S.x$ that is XOR-ed with message bytes.

• System status: Initialized. Click "Generate Key Pair" to sample private scalar d and evaluate public key Q = d · G.

Algorithmic Step Breakdown

  • Key Generation: Sample scalar $d \in_R [1, 2^b]$. Compute public key $Q = d \cdot G$ via scalar point multiplication.
  • Encryption: Pick random ephemeral scalar $k \in_R [1, 2^{16}]$. Compute $C_1 = k \cdot G$ and shared secret point $S = k \cdot Q = k \cdot (d \cdot G)$. Derive keystream bytes from $S.x$ and output ciphertext $C_2 = M \oplus \text{Keystream}(S.x)$.
  • Decryption: Recipient computes $S = d \cdot C_1 = d \cdot (k \cdot G) = k \cdot (d \cdot G)$. Reconstructs keystream and recovers $M = C_2 \oplus \text{Keystream}(S.x)$.

02 The Classical Caesar Cipher

A symmetric monoalphabetic substitution cipher shifting alphabet indices in the ring $\mathbb{Z}_{26}$. Encryption computes E(m) = (m + k) mod 26 and decryption computes D(c) = (c - k) mod 26. The shift scalar $k$ represents the sole secret parameter.

03 Architectural & Statistical Comparison

Fundamental divergence between classical symmetric character substitution and modern asymmetric group-theoretic constructs.

Dimension Toy ECC (EC-ElGamal / ECIES) Caesar Cipher
Cryptographic Paradigm Asymmetric (Public Key $Q$, Private Scalar $d$) + Hybrid XOR Symmetric (Single Shared Secret Scalar $k$)
Algebraic Structure Abelian Group $\mathcal{E}(\mathbb{F}_p)$ over $y^2 = x^3 + 7 \pmod p$ Finite Ring $\mathbb{Z}_{26}$ (Modular Integer Addition)
Ciphertext Determinism Probabilistic: Fresh ephemeral nonce $k$ produces distinct $C_1, C_2$ for identical plaintexts. Deterministic: Identical plaintexts always yield identical ciphertexts under same $k$.
Key Space Size Restricted Toy: $|\mathcal{K}| = 2^b$ ($2^{6}$ to $2^{16}$) • Production: $|\mathcal{K}| \approx 2^{256}$ Fixed: $|\mathcal{K}| = 26$ (effectively 25 non-trivial shifts)
Statistical Invariance Diffusion Achieved: Destroys unigram/n-gram frequency patterns; ciphertext appears uniform. Fatal Flaw: Unigram letter frequencies preserved exactly, merely translated cyclically.
Core Security Basis Intractability of Elliptic Curve Discrete Logarithm Problem (ECDLP) Secrecy of key $k$ (trivial brute-force / statistical recovery)

04 Statistical Cryptanalysis of the Caesar Cipher

Exploits language redundancy. Given an expected unigram frequency vector $\mathbf{p} = [p_A, \dots, p_Z]$ derived from a natural corpus (English), we test all candidate shifts $k \in \{0, \dots, 25\}$ against observed counts $O_i(k)$ minimizing the Pearson Chi-Square ($\chi^2$) metric: \chi^2(k) = \sum_{i \in \Sigma} \frac{(O_i(k) - L \cdot p_i)^2}{L \cdot p_i}

Empirical Recovery Rates (100 Synthetic Trials / Length)

Statistical Commentary: Under the Law of Large Numbers, as sample size $L \to \infty$, observed character frequencies converge almost surely to the true population distribution ($\frac{O_i}{L} \xrightarrow{p} p_i$). At very short lengths ($L \le 10$), high sample variance allows unrelated keys to achieve low $\chi^2$ scores purely by chance. Once $L \ge 40$, the $\chi^2$ divergence between the true shift and incorrect shifts becomes massive, driving accuracy to $100\%$.

05 Attacking the Toy ECC (Bounded Discrete Logarithm)

In the toy implementation, private scalar $d$ is restricted to $[1, 2^b]$. Unlike Caesar, the ciphertext leaks zero statistical language structure. However, the adversary can attack the public key $Q = d \cdot G$ directly by inverting the ECDLP via bounded scalar search.

• Attack engine ready. Ensure a key pair has been generated in Section 1, then trigger a discrete log recovery method.

Statistical Attack vs. ECC Bounded Search

The Caesar attack exploits information leakage (unscrambled frequency data). The ECC attack does not use ciphertext statistics at all; it exploits an artificial parameter restriction ($b \le 16$). Verification is exact and mathematical: $j \cdot G \stackrel{?}{=} Q$.

Why This Approach Fails on Production ECC

In real-world secp256k1, $d \in [1, 2^{256}]$. Linear search requires $\sim 2^{256}$ operations. The optimal square-root generic solver (Pollard's $\rho$ / BSGS) requires $\mathcal{O}(\sqrt{n}) \approx 2^{128}$ group operations. Even with a supercomputing cluster computing $10^{12}$ curve additions per second, $2^{128}$ operations requires approximately $1.07 \times 10^{19}$ years, guaranteeing computational intractability.

06 Architectural Vulnerability Analysis

Categorizing structural failure modes: parameter space truncation versus intrinsic design flaws.

• Restricted Key Space

  • Low Computational Entropy: For $b \le 16$, exhaustive linear point addition reaches $d$ in under 50 milliseconds directly in the browser.
  • Precomputation / Lookup Tables: Rainbow-style precomputed scalar multiplication tables $j \cdot G$ can be pre-calculated once and inverted in $\mathcal{O}(1)$ time.
  • Total Asymmetric Collapse: Recovering private key $d$ compromises every historical and future ciphertext encrypted under public key $Q$.

• Toy Design Flaws

  • Keystream Repetition (XOR): Deriving a stream by cycling $S.x$ every 32 bytes creates a multi-byte periodic key, rendering long ciphertexts vulnerable to Vigenère-style frequency cryptanalysis.
  • Malleability (Lack of CCA2 Security): Direct XOR without Message Authentication Codes (MAC) enables active adversaries to flip bits in $C_2$ predictably affecting recovered plaintext without detection.
  • Nonce Reuse Vulnerability: Repeating ephemeral nonce $k$ yields identical shared secrets ($S_1 = S_2$), allowing immediate plaintext XOR recovery: $C_A \oplus C_B = M_A \oplus M_B$.
  • Missing KDF & Curve Validation: Using raw coordinate $S.x$ instead of a cryptographic key derivation function (e.g., HKDF-SHA256) leaks field structure. Lack of point validation exposes the system to invalid-curve attacks.

• Modern Countermeasures

  • ECIES Standardization: Production systems utilize Elliptic Curve Integrated Encryption Scheme (ECIES), combining ECDH key agreement with ANSI X9.63 KDF, AES-256-GCM authenticated encryption, and HMAC-SHA256.
  • Pollard's Kangaroo Algorithm: The theoretical optimal attack for bounded intervals $[a, b]$, solving ECDLP in $\approx 2 \sqrt{b - a}$ group steps with minimal memory overhead.
  • Constant-Time Implementations: Protection against side-channel timing and cache attacks (e.g., Montgomery ladder point multiplication avoiding secret-dependent branching).
  • Post-Quantum Horizon: While classical curves resist Pollard's $\rho$ at 256 bits, Shor's quantum algorithm solves discrete logarithms in polynomial time $\mathcal{O}(n^3)$, motivating NIST Post-Quantum Cryptography standards (ML-KEM).
